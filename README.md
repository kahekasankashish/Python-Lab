# Python Lab

A collection of Python lab assignments completed as part of the B.Tech Computer Science and Engineering curriculum at Silicon University.

This repository contains solutions to 14 Python lab assignments, covering fundamental programming concepts, data structures, object-oriented programming, file handling, databases, NumPy, and Pandas.

## Topics Covered

- Python fundamentals, variables, data types and operators
- Conditional statements and bitwise operations
- Loops and numerical problem-solving
- Lists, tuples and dictionaries
- Functions, recursion, modules and packages
- Object-oriented programming, inheritance and abstraction
- Exception handling
- File handling and file operations
- SQLite database connectivity and SQL operations
- NumPy arrays and matrix operations
- Pandas DataFrames and data manipulation

## Technologies and Libraries

- **Language:** Python
- **Database:** SQLite
- **Libraries:** NumPy, Pandas
